FocusLock IoT – Smart Mobile Usage Restriction and Digital Discipline System

Project Overview

FocusLock IoT is a student project designed to encourage digital discipline and improve concentration during study sessions.

It combines an ESP32-based hardware system with a mobile application concept.

Main Features

- Mobile app usage restriction prototype
- ESP32-based control system
- Red and green LED indicators
- Buzzer alerts
- OLED status display
- Study timer
- Quiz and points system

Hardware Components

- ESP32 development board
- Red LED – GPIO 18
- Green LED – GPIO 19
- Buzzer – GPIO 23
- SSD1306 OLED display
- Connecting wires and breadboard

Software

- Arduino IDE / ArduinoDroid
- Android application (under development)
- C++ for ESP32
- Java for Android

Project Status

ESP32 hardware and dashboard prototype developed. Custom Android app restriction integration is under development.

Objective

To combine IoT technology and digital discipline features to help students reduce distractions and focus on their studies.

Important Note

The prototype's app restriction features are under development. The ESP32 hardware does not independently block Android applications.
